# Portfólio — Caio Vinicius

Site estático responsivo para publicar em `Viniicv/viniicv.github.io`.

## Publicação
1. Extraia os arquivos.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório `viniicv.github.io`.
3. Faça commit na branch `main`.
4. O GitHub Pages publica em https://viniicv.github.io/

## Projetos destacados
- Sistema de Atendimento Parlamentar
- EduTrack
- DocVerify
- DOE-SE

A vitrine é manual e mostra apenas esses quatro projetos; repositórios de exercícios e testes não são carregados automaticamente.
